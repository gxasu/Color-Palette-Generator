# Design Decision Record (DDR)

Interface Design Supervisor が管理する設計判断の記録。
`DESIGN.md` の Figma Inspired ガイドラインに基づく全 UI 決定を記録する。

## DDR-033: テーマ切り替えをアイコン起点のドロップダウンへ変更

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: ヘッダー右端のテーマ切り替えがテキスト `select` のままで、インポート / エクスポートや左パネルの追加導線と視覚言語が揃っていなかった。
**決定**: テーマ切り替えは icon-only の円形トリガーに変更し、クリック時に `ライト` `ダーク` `システム` のラベル付きドロップダウンを表示する。現在テーマは `sun` `moon` `monitor` の Feather アイコンで表現する。
**根拠**: ヘッダー内アクションのサイズと密度を揃えつつ、状態は視覚記号で短く伝え、選択肢は展開時にだけ言語化するほうが Figma Inspired の軽いクロームに合うため。

## DDR-034: タイトルを Roboto Condensed 700 に固定

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: アプリタイトル `Color Scale Generator` は従来の UI フォント設定では線が軽く、ヘッダーブランドとしての芯が弱かった。
**決定**: タイトルは `Roboto Condensed` の Weight 700 をローカル同梱で読み込み、ヘッダー専用のタイポグラフィとして使用する。
**根拠**: Figma Inspired の引き締まった UI に対して、横幅を圧縮した強めの見出しが最も安定して収まり、ロゴ横のタイトルとして視認性も高いため。

## DDR-035: 背景色ピッカーはベースカラーと同じスウォッチ構造に統一

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: `ライト背景` と `ダーク背景` の色ピッカーはベースカラーと同じ wrapper 構造を持っていたが、枠線幅だけが異なり、別コンポーネントのように見えていた。
**決定**: 背景色ピッカーのプレビュー面もベースカラーと同じ 40px / 2px border / 同一 radius のスウォッチとして扱う。
**根拠**: 同じ「色を直接選ぶ入力」は同じ形に揃えるほうが認知負荷が低く、右パネル内の編集ルールも明快になるため。

## DDR-001: カラーテーマをモノクロに統一

**日付**: 2025-02
**ステータス**: 採用
**コンテキスト**: カラーパレットジェネレーターの UI 自体が色を持つと、生成されるパレットの視認を妨げる。
**決定**: M3 の Primary / Secondary / Tertiary をすべてニュートラルグレーに統一する。機能色（Error, Success, Warning）のみ維持。
**根拠**: M3 では Primary は「ブランドの識別」に使用されるが、このツールのブランドは「色の中立性」であり、モノクロが最も適切。
**トークン設計**:
- Light: `--md-sys-color-primary: #5e5e5e`（Surface: #fafafa 系）
- Dark: `--md-sys-color-primary: #c8c8c8`（Surface: #131313 系）

## DDR-006: 明度チャートの高さとインタラクション

**ステータス**: 採用
**コンテキスト**: 明度カーブの視覚化と直接編集。
**決定**: Canvas ベースのチャート、高さ 480px。各データポイントをドラッグして明度（またはアルファ）を直接調整可能。

## DDR-009: カスタム入力の :focus-visible スタイル

**日付**: 2025-02
**ステータス**: 採用
**コンテキスト**: `.mode-name-input`、`.swatch-step-input`、`.card-name-input` 等のインライン編集入力は `border: none; outline: none` スタイルのため、キーボードフォーカスが視認不可能。WCAG 2.4.7（Focus Visible）違反。
**決定**: `:focus-visible` 擬似クラスで `outline: 2px solid var(--md-sys-color-primary)` を各カスタム入力に個別追加。マウスフォーカスは影響なし。
**根拠**: M3 の Focus Ring ガイドラインに準拠。`:focus-visible` はキーボードナビゲーション時のみ発火し、マウスクリック時の不要なフォーカスリングを回避。

## DDR-012: アクセシビリティ ARIA パターンの導入

**日付**: 2026-02-24
**ステータス**: 採用
**コンテキスト**: パレットカード、モードタブ、背景プレビュートグルなど主要なインタラクティブ要素に ARIA ロール・属性が未設定であり、スクリーンリーダーおよびキーボードユーザーにとって操作不能だった。
**決定**:
- パレット一覧: `role="listbox"` + 各カードに `role="option"` + `aria-selected` + roving tabindex
- モードタブ: `role="tablist"` + 各タブに `role="tab"` + `aria-selected` + roving tabindex
- 背景トグル: `role="group"` + `aria-label` + `aria-pressed`
- コントラスト表: `<caption>` + `scope="col"`
- Canvas チャート: `role="img"` + `aria-label`
- カラーピッカー全箇所: `aria-label`
- `<aside>` 要素: `aria-label` でランドマーク区別
**根拠**: WCAG 2.1 AA 準拠。M3 の Accessibility ガイドラインに沿ったセマンティクス。

## DDR-013: キーボードナビゲーションの実装

**日付**: 2026-02-24
**ステータス**: 採用
**コンテキスト**: パレットカード間、モードタブ間のキーボード操作（矢印キー、Enter/Space、Delete）が未実装だった。
**決定**:
- パレットカード: Arrow Up/Down で選択移動、Enter/Space で選択確定、Delete でパレット削除
- モードタブ: Arrow Left/Right でモード切り替え、Delete でモード削除
- roving tabindex パターンで Tab キーのフォーカスを1箇所に集約
- フォーカス復元: DOM 再構築後に `pendingFocusPaletteId` / `pendingFocusModeId` で自動復元
**根拠**: WCAG 2.1 SC 2.1.1（Keyboard）、M3 の Listbox / Tabs のキーボード操作パターンに準拠。

## DDR-017: prefers-reduced-motion メディアクエリの追加

**ステータス**: 採用
**コンテキスト**: アニメーション/トランジションが多数あるが、`prefers-reduced-motion` の考慮がなかった。

## DDR-028: アイコンシステムを Feather Icons に統一

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: `md-icon` + Material Symbols のリガチャ方式では、フォントが利用できない環境で `palette` や `tune` の文字列がそのまま表示されていた。Figma Inspired な黒白 UI に対しても、より細く簡潔なアウトラインアイコンが必要だった。
**決定**: UI アイコンを `feather-icons` に統一。`droplet`, `grid`, `sliders`, `upload`, `download`, `plus`, `x` を基準セットとし、`currentColor`・`stroke-width: 1.75` のモノクロアウトラインで表示する。
**根拠**: Feather Icons は 24x24 グリッドのシンプルなアウトライン SVG で、Figma 的な軽い線のアイコン言語と相性が良い。SVG ベースのため、フォント未読込時の文字化けも回避できる。

**コンテキスト**: `DESIGN.md` 適用時のグローバル上書きで `[data-theme="light"]` と `[data-theme="dark"]` に同一の白テーマ値を設定してしまい、テーマ切り替えの状態は変わっていても UI の見た目が変化しなかった。
**決定**: Figma Inspired のモノクロ方針を維持しつつ、ライトは白地黒文字、ダークは黒地白文字の別トークンに分離した。主要ボタンもライトでは黒 pill、ダークでは白 pill に反転するようテーマ別変数に切り替えた。
**根拠**: モノクロ UI の一貫性を保ちながら、テーマ切り替えが視覚的にも即座に分かる必要があるため。

## DDR-030: 背景色ピッカーをベースカラーと同じ塗り面 UI に統一

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: パレット設定内のライト背景・ダーク背景ピッカーはブラウザ既定の小さい color input がそのまま見えており、ベースカラーの大きめの塗り面プレビューと視覚的一貫性がなかった。
**決定**: 背景色ピッカーもベースカラーと同じ `color-picker-wrapper` + `color-preview` 構成に変更し、色面がしっかり見える 40px 角のスウォッチ UI に統一した。
**根拠**: 設定内の色選択 UI を同一パターンに揃えることで、どこをクリックすると色を変えられるかが直感的になり、Figma Inspired な整った面構成にも合うため。

## DDR-031: ヘッダー余白と左パネル追加 UI の再編

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: ヘッダーのインポート・エクスポート・テーマ切り替えの間隔が詰まって見え、左パネルでは `パレット一覧` が改行されていた。また、追加と Alpha が別ボタンで並ぶ構成は情報密度が高く、視線が散りやすかった。
**決定**: ヘッダーアクションの gap を拡大し、左パネルでは見出しを1行固定にしたうえで、追加 UI を icon-only の円形ボタン + ドロップダウンメニューへ再編した。メニュー内で `通常パレットを追加` と `Alpha パレットを追加` を選べる構成にした。
**根拠**: Figma Inspired な黒白 UI では、アクションは密集させすぎず、種類の選択は必要なタイミングで開く方が見通しが良い。追加操作を1か所へ集約すると、左パネルの見出し周りも整理される。

## DDR-032: Feather アイコンを slotted wrapper 経由で表示

**日付**: 2026-04-20
**ステータス**: 採用
**コンテキスト**: `md-filled-tonal-button` に直接差し込んでいた Feather SVG アイコンが、ボタン背景上で視認できない状態になっていた。
**決定**: インポート/エクスポートのアイコンは `slot="icon"` を持つ wrapper 要素の内側に配置し、ボタンホスト自体にも `color` を与えて、slotted SVG がラベル色を継承できるようにした。
**根拠**: slotted icon の受け皿を明示することで Material Web ボタンとの整合が安定し、黒ボタンでもアイコンが確実に見えるため。
